# Code of Conduct

Dayphony contributors are expected to make participation respectful and welcoming.

Be considerate, accept constructive feedback, and focus criticism on ideas and code.
Harassment, discrimination, threats, unwanted sexual attention, deliberate exposure
of private information, and sustained disruption are not acceptable.

Project maintainers may remove, edit, or reject contributions and participation that
violate these expectations. Report conduct concerns privately to the repository owner
through their GitHub profile. Reports will be reviewed respectfully and as
confidentially as practical.
